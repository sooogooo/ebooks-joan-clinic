# 天人合一与医美 - 静态网站项目

这是一个基于 Next.js 构建的现代化静态网站，展示《天人合一与医美》这本关于医美美学的专业书籍。

## 项目特色

- 🎨 **现代设计**: 采用中性优雅的设计风格，体现医疗专业性与时尚美学的平衡
- 📚 **丰富内容**: 包含完整的书籍内容，分为四大部分十个章节
- 📊 **可视化展示**: 集成 Mermaid 图表和自定义 SVG 插图
- 🎯 **交互体验**: 流畅的动画效果和交互式组件
- 📱 **响应式设计**: 完美适配桌面、平板和移动设备
- ⚡ **性能优化**: 静态生成，快速加载，SEO 友好

## 技术栈

- **框架**: Next.js 14 + TypeScript
- **样式**: Tailwind CSS + Framer Motion
- **图表**: Mermaid + 自定义 SVG 组件
- **部署**: 支持静态导出，可部署到任何静态托管服务

## 项目结构

```
src/
├── app/                    # Next.js App Router
│   ├── page.tsx           # 首页
│   ├── contents/          # 内容页面
│   ├── about/             # 关于页面
│   └── layout.tsx         # 布局文件
├── components/            # 可复用组件
│   ├── Header.tsx         # 导航头部
│   ├── Footer.tsx         # 页脚
│   ├── ChapterTemplate.tsx # 章节模板
│   ├── MermaidChart.tsx   # Mermaid 图表组件
│   └── svg/               # SVG 插图组件
├── data/                  # 数据文件
│   └── bookData.ts        # 书籍内容数据
├── lib/                   # 工具函数
│   ├── config.ts          # 网站配置
│   ├── utils.ts           # 通用工具
│   └── search.ts          # 搜索功能
├── styles/                # 样式文件
│   ├── globals.css        # 全局样式
│   └── plugins.js         # Tailwind 插件
└── types/                 # TypeScript 类型定义
```

## 开发指南

### 环境要求

- Node.js 18+
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 静态导出

```bash
npm run export
```

```bash
npm run lint
```

## 部署说明

### Vercel 部署
1. 连接 GitHub 仓库
2. 设置构建命令: `npm run build`
3. 设置输出目录: `out`
4. 自动部署

### 其他静态托管
1. 运行 `npm run export`
2. 将 `out` 目录上传到静态托管服务
3. 配置自定义域名（可选）
